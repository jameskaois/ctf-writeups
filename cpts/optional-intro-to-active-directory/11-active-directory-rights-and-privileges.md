# Section 11: Active Directory Rights and Privileges

Optional Module: Intro to Active Directory

---

## Questions & Answers

### 1. What built-in group will grant a user full and unrestricted access to a computer?

**Answer:** `Administrators`

---

### 2. What user right grants a user the ability to make backups of a system?


**Answer:** `SeBackupPrivilege`

---

### 3. What Windows command can show us all user rights assigned to the current user?

**Answer:** `whoami /priv`
